# 能力与缺口 / Capabilities and limits

This is a public **workflow candidate**, not an installer or live validation report. It contains no daemon, scheduler, sender, identity store, role-registration implementation or agent launcher. Formal business acceptance remains **0/33; paired comparisons 0/15**.

| 层 / Layer | 本包如何使用 / Use | 实证边界 / Boundary |
|---|---|---|
| Official Herdr | Read installed `herdr --skill` and `herdr --help` for supported IDs, prompt/read/wait and caller rules | The skill defaults to an internal caller. Explicit user authorization for an existing external target can override that skill default, only through a supported exact selector and verified original endpoint. Keep the real environment and existing task controller; a selector grants no authority. No formal live dispatch is certified here. |
| RaviTharuma/cmux-herdr | Optional third-party UI/topology bridge | Not Herdr official. Pills, cached association and role labels do not prove native identity, message reading or task acceptance. |
| MAC Herdr/cmux profiles | Use the task's already-bound controller for transport, intent, identity, receipts and recovery | Public reference `d652490` is documentation provenance, not permission to migrate old tasks. Pure cmux remains supported by its own applicable profile. |
| Nested inner/outer skills | Assign chapter work, consume results and coordinate chapter supervisors with senior | One shared contract; four routing modes and five rules; no new transmission protocol or enforcement service. |
| Offline chapter delta checker | Validate the existing form or selected populated deltas; optionally verify local file references and require a recorded accepted decision | [Usage](../../docs/nested-research-skills.md#check-the-chapter-delta--檢查章增量). Structural checks do not prove scientific acceptance, live delivery, historical review-ledger continuity or resource release. No input is modified. |
| Thesis-refiner | Apply scientific/evidence and manuscript acceptance appropriate to the deliverable | Public reference `653fd8c`; transport choice does not downgrade domain rules. Existing pinned tasks retain their original source. |
| 60-second progress and stopping | Active owner reports within available scheduling opportunities; records gaps and stops | Agent responsibility, not a crash-proof timer or a new recurring model prompt. |
| Review and shared resources | Preserve the baseline's total three-round budget; one writer and original leases | A review pass does not release Word/Zotero or authorize publication; TTL or idle status is not a release receipt. |
| Local historical role-display work | The predecessor package recorded a machine-specific CLI/help installation check | No private installer or receipt is bundled. It established neither actual role registration nor active UI loading; it is not a public prerequisite or universal installed fact. |

For nested destinations the outer workspace is a directory entry; actual delivery must reach the verified inner endpoint through a supported and authorized route. Never paste the message into the outer Herdr shell. Missing route capability is `ROUTE_UNAVAILABLE`, not permission to invent a new sender.

Only fields needed for the next action are required. Unrelated chapter gaps do not stop independently authorized work. A native endpoint outside Herdr legitimately uses `inner_herdr: null`. Existing controllers, unknown attempts, accepted artifacts and resource leases retain their original ownership.

See [public source pins](sources.json) and the [layer guide](../../docs/nested-research-skills.md). Package readability, installation, client loading, task enrollment, native delivery, body consumption, scientific acceptance and resource release are different claims.
